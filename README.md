# Cyclistic Case Study

Questo progetto contiene l'analisi di un caso studio svolto durante il corso **Google Data Analytics**.

## Obiettivo
L'obiettivo del caso studio è analizzare i dati disponibili per individuare comportamenti, differenze e possibili insight utili alla comprensione del problema proposto nel progetto.

## Contenuto del repository
- `notebook/` → notebook Jupyter con il codice dell'analisi
- `docs/` → materiale di supporto del caso studio in formato PDF

## Librerie principali
- Pandas
- NumPy
- Matplotlib
- Plotly Express

## Attività svolte
- Importazione e unione dei dati
- Pulizia e preparazione del dataset
- Analisi esplorativa
- Osservazione di pattern e differenze nei dati
- Produzione di risultati utili all'interpretazione del caso

## File principali
- `notebook/cyclistic_case_study.ipynb`
- `docs/case-study.pdf`

## Nota sui dati
I file CSV originali non sono stati caricati nel repository a causa delle loro dimensioni elevate.  
Il dataset completo contiene comunque circa **6 milioni di righe**, ed è stato utilizzato per svolgere l'analisi descritta nel notebook.

## Nota finale
Questo progetto è stato realizzato come esercizio pratico di apprendimento e come parte della costruzione del mio portfolio in Data Analytics.
